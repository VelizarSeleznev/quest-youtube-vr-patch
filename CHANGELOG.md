# Changelog

## 0.1.0 — 2026-10-05

- Local, source-only patcher for native YouTube VR 1.88.10 on Quest.
- Pull from your headset or provide an original APK.
- Verified Google signer, pinned Apktool and unique ad-method fingerprint.
- Separate app, persistent private signing key and unchanged native libraries.
- Portable Python CLI with source checks on Linux, macOS and Windows.
- Initial Quest 3 owner-confirmed sign-in and playback.
